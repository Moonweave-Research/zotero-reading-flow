# Screenshot provenance

The 1.3.8 captures are original, unedited images of English Zotero 10.0.6 for macOS running the released 1.3.8 build in a separate test profile. The 1.3.9 reading-start capture is an original, unedited image of Zotero 10.0.6 with a Korean host-app locale and the 1.3.9 QA source from the exact tree now tagged and released as 1.3.9. None are generated mockups or contain personal library records. Window layout changes and sample status choices were confined to isolated test profiles. Version 1.3.9 is available from the [latest release](https://github.com/Moonweave-Research/zotero-reading-flow/releases/latest).

Screens represent separate moments in their sample workflows, not one simultaneous snapshot. The reader toolbar capture shows page 4; the library, panel, and statistics captures show bookmark page 4 and automatic last viewed page 8. Those captures use the published 1.3.8 build. The 1.3.9 QA-source capture demonstrates the explicit start date without implying PDF reading activity or pages read; its source tree is the one published in the 1.3.9 release.

The sample titled QA — Unsupported record retains a legacy Important record after earlier compatibility testing; the title is a fixture label, not a current parser-error diagnosis. Its Unassigned + Important display demonstrates that the flag does not imply a reading stage.

The sidebar name can be truncated by Zotero's native sidebar width; its full name is Reading Flow — Tracked Papers, as shown in Settings. Native window captures keep original aspect ratios and full context. No UI text was relabeled in an image. Superseded screenshots were removed from the current tree; originals remain in Git history.

For new captures, use non-sensitive sample items, preserve the original pixels, and update captions when the UI changes. Never publish personal paper titles, notes, paths, or library metadata.
